# Estudos de Git e GitHub


## O que é Git? 
Git é um sistema de contole de versão que permite aconpannhar e gerenciar as alterações de um projeto.
 
 
 ## O que é branch? 
Branch é uma ramificação do projeto usada para desenvolver ou testar mudanças separadamente.

## O que é Tag?  
É uma marcação usada para identificar uma versão ou ponto imortante do projeto.

## O que é origin?
Origin é o nome dado pelo Git ao reósitorio remoto  principal, geralmente o reposiório no GitHub. x  

## O que é Remote?
É a conexão do meu repositório local com um repositório remoto.

## Para que serve Clone? Como se usa?
Serve para copiar um repositório remoto para meu computador. Uso `git clone`.

## Para que serve Pull? Como se usa?
Serve para baixar e atualizar as alterações do repositório remoto. Uso `git pull`.

## Para que serve Commit? Como se usa?
Serve para salvar as alterações no histórico do projeto. Uso `git commit`.

## Para que serve Push? Como se usa?
Serve para enviar minhas alterações para o repositório remoto. Uso `git push`.?
